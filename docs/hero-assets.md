# Homepage hero assets

- `assets/earth.jpg`: Earth surface texture from the three.js example assets, downloaded 2026-09-30: https://raw.githubusercontent.com/mrdoob/three.js/dev/examples/textures/planets/earth_atmos_2048.jpg
- `assets/haze-grain.svg`: procedural noise created for this site.
- Aircraft geometry and flight rendering are implemented in `hero.js` using WebGL, without added libraries.

The scene pauses outside the viewport and in hidden tabs. Reduced motion disables the flight. The lead form keeps the existing server submission handler.
